# Vidyam deAi website

Next.js 16 marketing site for Vidyam deAi. See `CLAUDE.md` for the brief and rules, `docs/` for architecture and content status.

```bash
npm install
npm run dev     # http://localhost:3000
```

Copy `.env.example` to `.env.local` to send form leads to Google Sheets / email. Without it, leads are printed in the terminal.
